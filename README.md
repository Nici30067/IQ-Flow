# IQ-Flow-Flashcards

This is an open source Project by developers for developers to visualize futuristic and modern user interface & user interaction. Maybe some of the displayed features and designs will be used by big flashcard apps ;)

## App Architecture (Backend)
-Der wichtigste Teil der Umsetzung: Einbindung von Mathe Bibliheken(Katex...)  
-Beim Programmieren sowie bei der UI: KISS(Keep it simple,stupid) und DRY(dont repeat yourself), YAGNE(you aint gonna need it)  
-Es sollte alles offline auf dem smartphone nutzbar sein (später dann auch online mit login)


## UI (Frontend)
-Stylisches, on fleek design  
-Keinen krimskrams  
-Aber: Karteikarten Stats(x Karteikarten insgesamt gelernt in der gesmaten zeit)  
-Kategorien zur bewertung wie gut Karten sitzen: Schlecht, okay, sehr gut  
-Sprachen: Englisch, Deutsch (...)  
-Übersicht an gelernten Karten, Noch zu lernenden karten  
-Möglichkeit zum Download eines Decks
-der "jetzt lernen Button" muss eine süchtig machende Animation haben(bsp: Rakete die einmal um button fliegt mit weißem Punkt + dazu Vibration)
-Nach Appinstallation ist ein Trivia Kartenset standartmäßig bei jedem drauf um interaktion zu vereinfachen
-Nachdem alle Karten für heute gelernt wurden, soll ein screen kommen, der bittet hoch zu swipen. Geschieht dies, Kommen geile Animationen, wo der Streak um 1 tag erhöht wird und im hintergrund dazu passende vibrationen sind.


## APP-Logic
-Bei Karteikarten: Vorder & Rückseite; Clozen(spaces unscharf/ausgeblendet); Multiple choice Fragen  
-Lernalgorythmus: Spaced Learning  
-Karteikarten in mehreren Schritten ausgeben
-Zieldatum eingeben (= Klausurdatum)-> Empfehlung von Gelernten Karten/Tag
