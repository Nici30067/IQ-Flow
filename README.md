# IQ-Flow-Flashcards

## App Architecture (Backend)
-Der wichtigste Teil der Umsetzung: Einbindung von Mathe Bibliheken(Katex...)  
-Beim Programmieren sowie bei der UI: KISS(Keep it simple,stupid) und DRY(dont repeat yourself), YAGNE(you aint gonna need it)  
-Es sollte alles offline auf dem smartphone nutzbar sein (später dann auch online mit login)


## UI (Frontend)
-Stylisches, on fleek design  
-Keinen krimskrams  
-Aber: Karteikarten Stats(x Karteikarten insgesamt gelernt in der gesmaten zeit)  
-Kategorien zur bewertung wie gut Karten sitzen: Schlecht, okay, sehr gut  
-Sprachen: Englisch, Deutsch (...)  
-Übersicht an gelernten Karten, Noch zu lernenden karten  
-Möglichkeit zum Download eines Decks


## APP-Logic
-Bei Karteikarten: Vorder & Rückseite; Clozen(spaces unscharf/ausgeblendet); Multiple choice Fragen  
-Lernalgorythmus: Spaced Learning
